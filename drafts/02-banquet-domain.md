# 宴会行业术语与业务链（待审阅）

状态：通用调研草稿，不代表任何具体客户的实际流程。

典型业务链：客户线索 → 沟通与预订 → 订单 → 宴会厅档期 → 桌数与套餐 → 物料需求 → 采购 → 到货与入库 → 库存 → 收款、付款与财务核对。每个箭头都需要确认交接人、凭证和异常处理。

| 术语 | 初步含义 | 访谈时应核对 |
| --- | --- | --- |
| 线索 | 潜在宴会需求 | 同一客户重复咨询如何识别 |
| 订单 | 已记录的服务安排 | 何时生效，定金与改单如何处理 |
| 档期 | 厅、日期和时段的占用 | 暂占、冲突、取消规则 |
| 桌数 | 预订、保底或实际开席数量 | 三种口径是否分别记录 |
| 套餐 | 菜品、服务和价格组合 | 替换菜品、加桌和临时增项 |
| 物料需求 | 为订单准备的物品与数量 | 如何从套餐转成用量，谁复核 |
| 入库 | 到货验收后记入库存 | 部分到货、退货、损耗 |
| 库存 | 指定地点和时点的账面数量 | 单位换算、盘点、实际可用量 |

系统账号数、实际使用人数和企业员工总数分别记录。手工录入、Excel 导入导出、数据库访问和正式 API 是不同的系统能力。不同门店、集团和软件供应商也分别建档，不因名称接近就合并。

待核实：婚宴与其他宴会是否同一流程；总部与门店分工；是否涉及外包服务；高频例外和旺季限制。
